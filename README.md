CodeAlpha Hangman Game

Project Description

This is a simple text-based Hangman Game developed using Python as part of the CodeAlpha Python Programming Internship.

Features

- Random word selection
- Guess one letter at a time
- Maximum 6 incorrect guesses
- Displays correct and incorrect guesses
- Shows win and game-over messages

Technologies Used

- Python
- Random module
- While loop
- If-else statements
- Strings and lists

How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open Command Prompt in the project folder.
4. Run the command:

python hangman_game.py
